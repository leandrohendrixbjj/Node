  1 · O QUE É LPUSH?
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

LPUSH significa Left Push. Ele adiciona um ou mais elementos à esquerda
(início) de uma lista.

Sintaxe:

  LPUSH <key> <elemento>

Exemplo:

  LPUSH tickets 101

                          LISTA: tickets

               esquerda                         direita
                  │                                │
                  ▼                                ▼
              ┌───────┬───────┬───────┬───────┐
   LPUSH ───► │  101  │  102  │  103  │  104  │
              └───────┴───────┴───────┴───────┘

  ┌──────────────────────────────┬─────────────────────────────────────────┐
  │ Comando                      │ Finalidade                              │
  ├──────────────────────────────┼─────────────────────────────────────────┤
  │ LPUSH tickets 101            │ Adiciona 101 à esquerda                 │
  │ LRANGE tickets 0 -1          │ Consulta todos os elementos             │
  │ LPOP tickets                 │ Remove e retorna o item da esquerda     │
  │ RPOP tickets                 │ Remove e retorna o item da direita      │
