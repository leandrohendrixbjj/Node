1. Com BRPOPLPUSH/BLMOVE, você normalmente teria 3 estados lógicos:

  - Pendente => que ainda não foi processado.
  - Processando => elementos que estão em processo de leitura do worker
  - Processado =>  elementos que já foram lidos pelo worker  

                ┌─────────────────┐
                │    PENDENTES    │
                │ aguardando      │
                └────────┬────────┘
                         │
                    BRPOPLPUSH
                         │
                         ▼
                ┌─────────────────┐
                │   PROCESSANDO   │
                │ em execução     │
                └────────┬────────┘
                         │
                    processamento
                         │
                         ▼
                ┌─────────────────┐
                │   PROCESSADOS   │
                │ concluídos      │
                └─────────────────┘


2. E se o worker morrer?
  - Esse item foi retirado da fila, mas não foi confirmado como concluído.

      processing
        │
        │ worker morreu
        ▼
      BLMOVE
        │
        ▼
      pending

   - Outro worker poderá processá-lo.   

      processing
          │
          │ worker morreu
          ▼
        BLMOVE
          │
          ▼
      pending

3. Fluxo

    PENDENTES
        │
        │ BRPOPLPUSH / BLMOVE
        ▼
    PROCESSANDO
        │
        ├──── Worker terminou ────► PROCESSADOS
        │
        │ Worker morreu
        │
        └──────── recovery ───────► PENDENTES
