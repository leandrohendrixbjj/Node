Com BRPOPLPUSH / BLMOVE, a fila costuma ter três estados:

  • Pendente      → ainda não foi processado
  • Processando   → o worker já leu e está executando
  • Processado    → o worker já concluiu

                         ▼
                ┌─────────────────┐
                │   PROCESSANDO   │
                │   em execução   │
                └────────┬────────┘
                         │
                   processamento
                         │
                         ▼
                ┌─────────────────┐
                │   PROCESSADOS   │

  2 · E SE O WORKER MORRER?
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

O item saiu da fila principal, mas não foi confirmado como concluído.
Um BLMOVE devolve esse item para a fila de pendentes. Outro worker
pode processá-lo.

                  processing
                      │
                      │  worker morreu
                      ▼
                    BLMOVE
                      │
                      ▼
                   pending
