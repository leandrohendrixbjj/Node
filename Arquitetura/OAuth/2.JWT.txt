  1 · O QUE É JWT?
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

JWT é um padrão para representar informações de forma compacta e assinada
entre sistemas.

A confusão comum é tratar JWT como um tipo de autenticação. JWT é o
formato do token.


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  2 · ESTRUTURA
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  HEADER.PAYLOAD.SIGNATURE

Header — informa o algoritmo utilizado:

  {
    "alg": "RS256",
    "typ": "JWT"
  }

Payload — contém os claims, as informações sobre o token:

  {
    "sub":   "123",
    "email": "leandro@example.com",
    "role":  "admin",
    "exp":   1791000000
  }

Signature — verifica se o token foi alterado e, conforme o algoritmo e a
chave, confirma a origem.

  3 · JWT NÃO É SINÔNIMO DE AUTENTICAÇÃO
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  ┌──────────────┬────────────────────────────────────────────────────────────┐
  │ Token        │ Relação com JWT                                            │
  ├──────────────┼────────────────────────────────────────────────────────────┤
  │ Access Token │ Pode ser um JWT                                            │
  │ ID Token     │ É um JWT no OpenID Connect                                 │
  │ Session ID   │ Normalmente não é JWT. A sessão pode ser um JWT            │

  4 · JWT NÃO É CRIPTOGRAFADO POR PADRÃO
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

A assinatura não esconde o conteúdo. Um segredo colocado no payload continua
legível para quem decodificar o token.
