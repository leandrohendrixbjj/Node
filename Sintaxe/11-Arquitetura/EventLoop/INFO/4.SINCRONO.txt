================================================================================
                    OPERAÇÕES SÍNCRONAS — SEM THREAD POOL
================================================================================

Perceba que não existe Thread Pool.

O próprio thread principal do Node faz a chamada ao sistema operacional e
fica esperando o retorno.

Enquanto isso:

    • o Call Stack continua ocupado
    • o Event Loop não consegue avançar
    • nenhum callback é executado
    • nenhuma requisição HTTP é atendida
    • nenhum timer dispara
