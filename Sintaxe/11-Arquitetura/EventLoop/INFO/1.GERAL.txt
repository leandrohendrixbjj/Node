┌─ Visão geral ────────────────────────────────────────────────────┐
│                                                                   │
│  O Node.js é composto por três partes principais:                │
│                                                                   │
│    • V8          →  executa TODOS OS JavaScript                   │
│    • libuv       →  gerencia I/O assíncrono e Event Loop          │
│    • APIs Node   →  http, fs, timers, etc.                      │
│                                                                   │
└───────────────────────────────────────────────────────────────────┘

┌─ Fluxo de execução ──────────────────────────────────────────────┐
│                                                                  │
│                    ┌─────────────────┐                           │
│                    │   Código JS     │                           │
│                    └────────┬────────┘                           │
│                             │                                    │
│                             ▼                                    │
│                    ┌─────────────────┐                           │
│                    │ V8 (Call Stack) │                           │
│                    └────────┬────────┘                           │
│                             │                                    │
│        ┌────────────────────┴────────────────────┐               │
│        │                                         │               │
│        ▼                                         ▼               │
│ ┌───────────────┐                     ┌────────────────────┐      │
│ │ nextTick      │                     │    Node APIs       │      │
│ │ queue         │                     │ (timers, fs, http) │      │
│ └──────┬────────┘                     └────────┬───────────┘      │
│        │                                       │                  │
│        ▼                                       ▼                  │
│ ┌───────────────┐                     ┌────────────────────────┐  │
│ │ Microtasks    │                     │ Macrotasks (libuv)     │  │
│ │ (V8 / Node)   │                     │                        │  │
│ └──────┬────────┘                     │ timers (setTimeout)    │  │
│        │                              │ poll (I/O, HTTP)       │  │
│        ▼                              │ poll (sockets TCP, fs) │  │
                                        │ check (setImmediate)   │  │
│ ┌───────────────┐                     │                        │  │
│ │ Call Stack    │◄────────────────────┤                        │  │
│ │ (execução)    │                     └────────┬───────────────┘  │
│ └───────────────┘                              │                  │
│                                                ▼                  │
│                                       ┌─────────────────┐         │
│                                       │ Sistema Operac. │         │
│                                       └─────────────────┘         │
│                                                                  │
└──────────────────────────────────────────────────────────────────┘

I/O         → operações de entrada e saída
HTTP        → requisições/respostas de rede
fs          → sistema de arquivos (File System)
sockets TCP → conexões de rede TCP (banco, APIs, servidores)
