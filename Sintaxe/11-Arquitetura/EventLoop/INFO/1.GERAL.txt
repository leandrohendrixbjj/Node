Obs: No Node.js temos a Next Tick Queue, controlada pelo Node.js, e a Microtask Queue, gerenciada pelo V8. 
     Ambas têm prioridade sobre o avanço normal do Event Loop.

I/O → operações de entrada e saída ( FS )
HTTP → requisições/respostas de rede
sockets → conexões de rede TCP (banco, APIs, servidores)
setImmediate → Quando a fase de Poll(sem eventos de IO pendentes na fila), o eventLoop avança para fase de check, 
               onde são executados os callbacks exemplo setImmediate
