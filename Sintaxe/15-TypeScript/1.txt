================================================================================
                            O QUE É TYPESCRIPT?
================================================================================

O TypeScript é um superset do JavaScript desenvolvido pela Microsoft.

"Superset" significa que todo código JavaScript válido também é um código
TypeScript válido.

Por exemplo, este JavaScript funciona perfeitamente em TypeScript:

    function somar(a, b) {
        return a + b;
    }

    console.log(somar(10, 20));


O diferencial é que o TypeScript adiciona recursos que o JavaScript não
possui, sendo o principal deles:

    • Tipagem estática
    • Melhor suporte da IDE
    • Detecção de erros durante o desenvolvimento
    • Recursos modernos da linguagem


================================================================================
                      POR QUE O TYPESCRIPT FOI CRIADO?
================================================================================

Imagine este código JavaScript:

    function multiplicar(a, b) {
        return a * b;
    }

    console.log(multiplicar(10, "5"));

O JavaScript aceita isso.

Resultado: 50


Agora outro exemplo:

    function mostrarNome(nome) {
        console.log(nome.toUpperCase());
    }

    mostrarNome(100);

O erro só acontece quando você executa:

    TypeError: nome.toUpperCase is not a function


Ou seja:

    O JavaScript normalmente descobre muitos erros em tempo de execução
    (Runtime).

    O TypeScript tenta descobrir esses erros antes de executar o programa.


================================================================================
                         A PRIMEIRA VANTAGEM: TIPOS
================================================================================

No TypeScript podemos dizer qual tipo esperamos:

    function mostrarNome(nome: string) {
        console.log(nome.toUpperCase());
    }

Agora:

    mostrarNome(100);

A IDE já mostra:

    Argument of type 'number'
    is not assignable to parameter of type 'string'.

Nem precisa executar o programa.


--------------------------------------------------------------------------------
                              OUTRO EXEMPLO
--------------------------------------------------------------------------------

Sem TypeScript:

    let idade = 20;
    idade = "vinte";

O JavaScript aceita.


Com TypeScript:

    let idade: number = 20;
    idade = "vinte";

Erro:

    Type 'string' is not assignable to type 'number'.
